# FBBP MCP RAG Server Interface Guide

[English](./INTERFACE_GUIDE_EN.md) | [中文](./INTERFACE_GUIDE_CN.md)

## Purpose

MCP tool server exposing private RAG and scientific lookup capabilities.

## Intended Readers

Tooling reviewers, agent-framework users, and interviewers checking standard client integration.

## How To Read This Repository

- Start from README.md, FINAL_RESULT_SUMMARY.md, and docs/mcp_tool_api_reference.md.
- configs/ contains service and runtime examples.
- examples/ contains client configuration examples.
- reports/final_release/latest/ contains acceptance evidence.

## Repository Boundary

This repository is an upload-ready public package. Local paths, runtime caches, logs, private raw data, model weights, and temporary working files were excluded before upload.
